# B.I.L-E
B.I.L-E or Bread Incorporated Logistics Exterminator Is a passion project Rogue-like game where you play as a series of interns hired on to wear the B.I.L-E suit to try and take down Bread Incorporated's Rivals!

Each intern can be retrofitted in various suits to take on the corporate headquarters of each company! Although beware, if your intern dies in a run, the headquarters will be randomized and you will need to relearn the terrain! Find upgrades, weapons, new suits and send them down the mail chute so that future interns can benefit from your permanent overtime!

Currently the project is in a very early state, and may not reflect the current build of the game.

Development is underway using Obsidian for documentation and Unity 6 for development work.
